# FEATURE: Daily Habit & Streak Tracker SPA

## 1. Context & Purpose
A client-side Single Page Application (SPA) built with React + Vite+ to track daily habits, visualize active streaks, celebrate consistency milestones, and display weekly completion analytics with instant visual feedback.

## 2. Domain Entities & Models
- Habit: id (UUID), title (string), category (health, learning, productivity, mindfulness), targetDaysPerWeek (number), createdAt (Date).
- HabitCompletion: habitId, date (ISO string YYYY-MM-DD), completed (boolean).
- StreakMetric: currentStreak (consecutive days), longestStreak (historical record), weeklyCompletionRate (percentage 0-100%).

## 3. UI Screens, Routes & Components
- / (Root route in routes-manifest.json): Interactive dashboard displaying today's habit list and weekly progress overview.
- HabitCard: Atomic card component per habit with circular completion toggle, visual streak badge, and category tag.
- StreakRing: SVG circular progress indicator displaying weekly completion percentage.
- EmptyStateHabits: Accessible empty state with encouraging copy and a Call to Action (CTA) to create the first habit.
- Styling & Design Tokens: Powered by Google Stitch (specs/habits/designs/tokens.css) consuming semantic CSS variables (--color-primary, --color-surface, --radius-md, --space-4).

## 4. Key Acceptance Criteria (Gherkin Scenarios)
- Scenario 1 (Mark habit as completed):
  Given the user is viewing today's pending habit list
  When they activate the completion control on a habit card
  Then the status changes to completed, the current streak increments by 1, and the StreakRing animates.

- Scenario 2 (Streak reset on missed day):
  Given a habit whose last completion timestamp was more than 48 hours ago
  When the user opens the application
  Then the current streak resets to 0 while preserving the all-time longest streak record.

- Scenario 3 (Keyboard navigation & accessibility):
  Given a user navigating exclusively via keyboard
  When they focus the HabitCard completion control with 'Tab' and press 'Space' or 'Enter'
  Then a visible focus ring (:focus-visible) of at least 2px appears and the habit toggles state accessibly (aria-pressed updated).

## 5. Technical Constraints & Quality Gates
- Modular Clean Architecture under src/features/habits/ (domain, application, ui).
- Strict Atomic Design: Exactly one React component per file (HabitCard.tsx, StreakRing.tsx, etc.).
- Ghost Classes Gate: Every class name referenced in JSX must exist in tokens.css or declared stylesheets.
- Production budget: Compiled Rolldown bundle size under 250KB per chunk.
- Unit tests using Vitest and Testing Library for user interactions and empty states.

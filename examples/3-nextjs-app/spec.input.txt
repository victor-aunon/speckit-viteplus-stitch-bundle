# FEATURE: SaaS Pricing & Subscription Tier Selector

## 1. Context & Purpose
A public marketing pricing page built for Next.js App Router (src/app/pricing/page.tsx). Allows potential customers to compare subscription tiers (Starter, Pro, Enterprise), toggle between monthly and annual billing with automatic discounts, and proceed to checkout with their selected plan.

## 2. Domain Entities & Types
- PricingPlan: id ('starter' | 'pro' | 'enterprise'), name (string), description (string), monthlyPrice (number), annualPricePerMonth (number), isPopular (boolean), features (FeatureItem array), ctaLabel (string).
- FeatureItem: title (string), included (boolean), tooltipText (optional string).
- BillingInterval: 'monthly' | 'annual' (with visible percentage savings badge).

## 3. UI Routes & Component Structure
- /pricing (Next.js App Router page at src/app/pricing/page.tsx): Responsive layout with marketing headline, billing cycle switch, and a 3-column pricing grid (collapsing to 1 column on mobile).
- PricingCard: Atomic card component with visual highlighting for the 'Pro' tier (popular badge), feature checklist with checkmark icons.
- BillingIntervalToggle: Accessible switch control (role='switch', aria-checked) toggling monthly and annual billing with a 'Save 20%' badge.
- PlanCtaButton: Call-to-action button linking directly to /checkout?plan=<id>&billing=<interval>.

## 4. Key Acceptance Criteria (Gherkin Scenarios)
- Scenario 1 (Switch to annual billing):
  Given the user is viewing monthly prices on /pricing
  When they activate the annual billing toggle
  Then card prices update to reflect the annual rate with a 20% discount and an annual billing label is displayed.

- Scenario 2 (Plan selection and checkout redirection):
  Given the user selects the 'Pro' plan with annual billing selected
  When they click the CTA button 'Get Started with Pro'
  Then a navigation link to '/checkout?plan=pro&interval=annual' is generated with the correct query parameters.

- Scenario 3 (WCAG 2.1 AA contrast & touch targets):
  Given the visual elements of the featured 'Pro' card
  When color contrast ratios are audited between text and background
  Then all body text meets a minimum contrast ratio of 4.5:1 (WCAG 2.1 AA) and interactive controls have a minimum touch target of 44x44px.

## 5. Technical Constraints & Quality Gates
- Next.js App Router structure under src/app/pricing/ (page.tsx, components, tests).
- Strict separation between Server Components (static layout) and Client Components ('use client' strictly on interactive toggle).
- Centralized environment configuration via src/config/env.ts (NEXT_PUBLIC_STRIPE_KEY, NEXT_PUBLIC_APP_URL); no direct process.env reads in UI components.
- Atomic Design: 1 component per file.
- Component tests using Vitest and Testing Library verifying price recalculations on toggle activation.
